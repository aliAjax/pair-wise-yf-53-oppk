# pair-wise-yf-53 开源项目发布列车准备和门禁控制台

## 源提示词摘要
维护者创建跨仓库发布，关联版本、负责人、阻断问题和待合并依赖，安排冻结时间与分批顺序。发布前检查依赖、阻断、超时确认和顺序冲突，支持冻结、降级、回滚准备状态及可追溯审计。

## 技术栈
React Router 7 框架模式 + TypeScript + Mantine + Redux Toolkit + RTK Query + React Hook Form + Zod + Lingui + dnd-kit。

## 已实现闭环
- 跨仓库发布列车、依赖门禁和阻断问题三类业务对象。
- 门禁确认、阻断关闭、发布冻结、回滚和恢复准备状态。
- 仓库顺序拖拽、表单校验、远端健康查询与审计历史。
- **可续作回滚队列**：仓库进入回滚后，直接或间接依赖它的已发布仓库
  按反向顺序（下游先滚、上游后滚；同层后发先滚）自动排队；前驱未处理完，
  后继留在队列。
- **断点续作**：远端拒绝时队列停在失败仓库，再次提交（或点「从断点继续」）
  从最近完成的位置重试；回滚编号为 `RB-{列车}-{仓库}@{版本}`，同一编号
  在队列与审计中始终只有一条执行记录，重试只更新该记录与尝试次数。
- **并发决定冲突（409 语义）**：同一仓库同时收到冻结与回滚请求时，先落的
  决定生效，另一个请求收到冲突提示并在「并发决定冲突」面板留痕。
- **历史数据回执**：旧数据里只有整列车回滚标记、没有逐仓库记录的发布列车，
  加载时自动按当时冻结版本、依反向发布顺序补录历史回执（标记为历史回执）。
- localStorage 持久化（带 schema 版本迁移）。
